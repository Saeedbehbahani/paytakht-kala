# License and Redistribution Review

## Ownership confirmation

On 2026-11-18, the project owner confirmed that they developed and own the original Paytakht Kala application source code and proprietary brand assets and that no other person or company holds conflicting publication rights to those original materials.

The owner has selected `GPL-3.0-or-later` as the proposed license, subject to final explicit approval before the first public push.

## Third-party dependencies

The locked Composer and npm dependency metadata was reviewed for redistribution compatibility. Declared licenses include MIT, BSD-3-Clause, Apache-2.0, ISC, 0BSD, MPL-2.0, Unlicense, CC0 alternatives, and Nette packages offering BSD/GPL licensing choices. These are compatible with distribution of the original project under GPL-3.0-or-later.

MPL-2.0 dependencies remain separately packaged dependencies under file-level copyleft terms. Dependency source is not copied into this repository; users obtain it from the declared package registries through Composer and npm.

## Bundled assets

The candidate contains only owner-confirmed Paytakht Kala icons and favicons. No third-party fonts, photographs, PDFs, archives, or opaque binary assets were found in the distributable source tree.

## Scope

The project license applies to original Paytakht Kala code and owner-created assets. Third-party packages retain their own copyright notices and licenses. The Paytakht Kala name and branding are licensed as included project assets under the project license; this does not imply endorsement of modified versions.

No unresolved third-party redistribution blocker was identified in the sanitized candidate. This is a release-engineering compatibility review, not legal advice.
